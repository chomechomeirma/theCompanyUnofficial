# theCompanyUnofficial
A fork of The Company game by Westane (build 5.12.1)

## Requirements

* [Tweego](https://www.motoslave.net/tweego/)
* [SugarCube 2.36.1](https://github.com/tmedwards/sugarcube-2/releases)

## How to Build

1. SugarCuber 2.36.1 should be added unzipped to the storyformats folder inside Tweego
2. Run the following command from the Tweego folder: tweego -f sugarcube-2-36-1 -l -o build/TheCompany.html src
